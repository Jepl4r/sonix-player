# Российские сервисы в Sonix R1 — решение (14.10.2026)

## Решение
- **Добавляем только «Звук» (zvuk.com, бывший СберЗвук).** Только в форке, под флагом сборки `SONIX_ZVUK`, автору upstream не предлагаем (неофициальный API, как у Яндекса).
- **VK Музыка — нет** (отказ X4; с 07.09.2026 у VK месячные лимиты и платный доступ к API для сторонних клиентов, Kate Mobile заблокирован 09.09.2026; аудио только с потерями).
- **МТС Музыка / KION — нет** (нет открытых клиентов и описаний API).
- **Вход в Звук — только через файл с токеном на карте.** QR-код и страница вставки токена в `sonixlink` выброшены совсем.

## Что известно об API Звука (по открытым клиентам)
- GraphQL: `POST https://zvuk.com/api/v1/graphql`; служебное: `https://zvuk.com/api/tiny` (профиль: `/api/tiny/profile`).
- Авторизация: заголовок `X-Auth-Token: <token>`. Подписи запросов нет.
- Обязательно для прохода антибота ServicePipe: браузерный `User-Agent`, `Origin: https://zvuk.com`, `Referer: https://zvuk.com/`. Блокировка = HTTP 418 или HTML вместо JSON.
- Поток: `mediaContents(ids:[ID!]!) { ... on Track { stream { expire expireDelta flac flacdrm high mid } } }`.
  - `flac` — FLAC в MP4 (progressive), без DRM, 16/24 бит, 44,1 кГц → распаковывать существующим `mp4flac.c`.
  - `flacdrm` — пропускать (играть `high`).
  - `high` = MP3 320 (подписка), `mid` = MP3 128 (без подписки).
  - Ссылки временные (`expire`) — при отказе загрузки перезапрашивать.
- Есть также типы `Episode` (подкасты) и `Chapter` (аудиокниги) — второй этап.
- Запросы-образцы (имена операций): `getStream`, `getFullTrack`, `getTracks`, `userTracks`, `userCollection`, `userPlaylists`, `getPlaylistTracks`, `getReleases`, `getArtists`, `search`, `quickSearch`, `synthesisPlaylist`, `listeningHistory`, `getEpisodes`, `getPodcasts`.
- Токен живёт дни–недели; при 401/403 — сессия истекла.
- Часть контента геоблокирована (может пропадать при входе из-за рубежа).
- Источники: github.com/trudenboy/zvuk-music (MIT, `zvuk_music/graphql/queries/*.graphql`, `utils/request.py`), github.com/trudenboy/ma-provider-zvuk-music (PR #151 — FLAC через GraphQL), github.com/oklookat/gozvuk.

## Вход: импорт токена с карты (общий механизм для всех сервисов)
1. Пользователь кладёт в корень карты `zvuk_token.txt` (USB с ПК или Wi-Fi-передача файлов).
2. Плеер ищет файл: при старте, при монтировании карты, при открытии страницы Звука.
3. Чтение: снять UTF-8 BOM, `\r`, пробелы; взять первую непустую строку; принимать также `zvuk_token.txt.txt` (скрытые расширения Windows). Лимит размера файла (например 4 КБ).
4. Проверка одним запросом профиля.
   - Успех → токен сохраняется во внутреннюю память (`/usr/data`, отдельный файл сессии рядом с `yandex_session.ini`, атомарная запись tmp+rename, права 0600), файл на карте **удаляется**, тост «Звук: вошли как …».
   - Нет сети / таймаут → файл не трогать, повторить при следующем поводе.
   - Токен неверный (401/403) → переименовать в `zvuk_token.txt.bad`, сообщение «Токен Звука не принят».
   - Антибот (418/HTML) → файл не трогать, сообщение «Звук заблокировал запрос».
5. Истёкший токен в работе → выход из сессии, сообщение «Токен Звука истёк — положите новый zvuk_token.txt на карту»; сохранённые на карте треки играют дальше.
6. Сессия Звука — в списке очистки factory reset.
7. Механизм общий («импорт аккаунта с карты»): потом `subsonic.txt` (адрес/логин/пароль), ключи Podcast Index / Last.fm. Каждый сервис регистрирует имя файла + функцию проверки.

## Порядок
0. **Spike (до кода модуля):** с плеера (не из облачного контейнера — zvuk.com оттуда, вероятно, недоступен) один `getStream` с реальным токеном через сетевой стек прошивки (http.c/tls.c, OpenSSL 1.1 устройства). JSON + ссылка `flac` → идём дальше. 418/HTML → модуль не делаем; запасной путь — мост на сервере (Python-библиотека → файлы → Navidrome → Subsonic на плеере).
1. Общий импорт с карты (~100–150 строк) + подключение Subsonic (`subsonic.txt`) — проверить механизм на том, что уже работает.
2. Модуль Звука по образцу модуля Яндекса (реестр провайдеров, кеш с лимитом/LRU/маркером незавершённости, офлайн «Сохранено на карте», «Загрузки», понятные ошибки с «Повторить»): лайки, плейлисты, поиск, релизы/исполнители, «Сохранить на карту», качество FLAC → 320 → 128. Флаг `SONIX_ZVUK`. Ориентир ~2–2,5 тыс. строк.
3. Второй этап: аудиокниги (`Chapter`) и подкасты (`Episode`) Звука, рекомендации (`synthesisPlaylist`).
