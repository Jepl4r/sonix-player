# Sonix Player — rekkod-mod: что изменилось относительно оригинала

Форк [Jepl4r/sonix-player](https://github.com/Jepl4r/sonix-player) для HiBy R1, ветка `sonix-r1` в [Rekkod-Tree/sonix-player-rekkod-mod](https://github.com/Rekkod-Tree/sonix-player-rekkod-mod).

| | |
|---|---|
| Точка форка | `1743e5b` от 12.10.2026 («Standby delay options, faster now playing covers, 32-bit FLAC playback») |
| Последнее слияние с оригиналом | `dd59cfc` от 12.10.2026 («Podcast rework»), более новых коммитов у автора нет |
| Собственных коммитов | 51 (без слияний) |
| Объём | 143 файла, +29 028 / −825 строк, включая перегенерированный `icons.c` и 90 новых строк перевода × 11 языков × 2 модели |
| Текущая версия | 1.2.3 (`6c0d07c`, 13.10.2026) |
| Проверка | Все сборки собраны (`check-abi`: ни одного символа glibc новее 2.22) и проверены в эмуляторе и на тестовых имитациях серверов. **На плеере ещё ничего не проверялось.** |

---

## 1. Коротко: чем форк отличается от оригинала

- **Свой сервер и Яндекс.** Новые источники музыки: **OpenSubsonic** (Navidrome, Gonic, Airsonic и др.) и **Яндекс Музыка** (вход по коду, «Мне нравится», «Моя волна», FLAC).
- **Общий интерфейс для стриминговых сервисов** вместо проверок «если Qobuz / если Tidal», разбросанных по коду.
- **Устойчивее к сети.** Загрузки в кеш докачиваются после обрыва Wi-Fi (HTTP Range), а Tidal в AAC (DASH/fMP4) теперь должен играть.
- **Bluetooth:**
  - частота соединения 44,1 кГц, «По треку» или 96 кГц;
  - кодек, громкость, режим LDAC и эквалайзер запоминаются для каждых наушников;
  - заряд любых наушников по HFP;
  - быстрее переподключение;
  - громкость не теряет синхронизацию после перезапуска bluealsa. Этот баг есть и в оригинале.
- **Библиотека:**
  - сборники без ALBUMARTIST держатся одним альбомом;
  - альбомы исполнителя идут по году;
  - «Перейти к исполнителю» из любого меню;
  - длительности треков и альбомов;
  - поиск по нескольким словам;
  - плитки «Недавно добавленные» и «Недавно играли»;
  - ReplayGain с предусилением и тегами Opus R128.
- **Скорость и батарея:**
  - главный экран рисуется раньше, редкие экраны строятся при первом открытии;
  - меньше записей на карту;
  - реже перерисовывается бегущая строка;
  - нет живого размытия во время анимаций.
- **Система:**
  - своя версия (1.2.x) и обновления «через интернет» из форка, а не из оригинала;
  - свой ключ для запечатанного файла ключей сервисов, поэтому Tidal, Qobuz, Podcast Index и Last.fm в этой сборке не работают (раздел 5).

## 2. По версиям

### 1.2.3 — 13.10.2026: исправления и частота Bluetooth

**Слияние с оригиналом**
- Уведомление «карта не вставлена» в Музыке и Аудиокнигах (`c4fedee`).
- Переработка подкастов (`dd59cfc`). Докачка подкастов после обрыва проверена после слияния.

**Bluetooth**
- **Громкость больше не теряет синхронизацию с наушниками после смены настроек** (частота, режим AAC, режим LDAC) и после смены кодека.
  - Причина: после перезапуска bluealsa регулятор громкости пытался привязаться к потоку раньше, чем наушники переподключались, и навсегда помечал его сломанным.
  - Теперь он ждёт, пока поток появится (сигнал `InterfacesAdded`), и привязывается заново.
  - Ошибка есть и в оригинале.
- **Кодек, выбранный вручную, возвращается** после перезапуска bluealsa, после сна и при пересоздании потока. Если наушники всё же ушли на другой кодек, появляется сообщение «Кодек сменился: LDAC → AAC».
- **Новые режимы частоты соединения:** «По треку» и «96 кГц», вдобавок к «Авто (48 кГц)» и «44,1 кГц».
  - «По треку»: треки 44,1 кГц идут на 44,1; 88,2 и 176,4 — на 88,2; 48 — на 48; 96 и 192 — на 96. 192 и 176,4 делятся ровно пополам.
  - Работает для LDAC. Частота меняется через `SelectCodec` с конфигурацией кодека, без перезапуска демона и только между треками.
  - Если наушники отказываются от частоты, это пишется в лог и соединение остаётся на прежней частоте, без повторных попыток.
  - Аварийное отключение: `[bluetooth] link_rate_select = 0`.
- **LDAC 990 и Wi-Fi-трансфер** договариваются с первого запуска bluealsa, без двойного перезапуска.

**Исправления по внешнему ревью**
- **Яндекс:**
  - опережающая загрузка следующего трека больше не обрывает играющий;
  - всплывающее окно передаётся в GUI-поток через `gui_post`;
  - убрана гонка между результатами фоновых задач на странице;
  - размер запроса лайков считается по фактическим ID.
- **fMP4:**
  - поток воспроизведения больше не крутится вхолостую, когда загрузка остановилась на краю;
  - добавлена проверка границ при разборе `trun`.
- **Отмена загрузок:** хватает места для обработчиков всех пяти сервисов; раньше пятый молча терялся.
- **Чтение файлов:** подсказка «последовательное чтение» (`posix_fadvise`) включается только для обычных FLAC.

### 1.2.2 — 13.10.2026: третья волна

**Источники музыки**
- **OpenSubsonic** — новая плитка «Subsonic» в «Стриминге».
  - Вход по адресу сервера, логину и паролю. Используется token-авторизация; пароль не хранится.
  - Разделы: исполнители, недавно добавленные, недавно игравшие, часто играемые, случайные альбомы, плейлисты, избранное, поиск.
  - Звёзды, добавление в плейлисты сервера, скробблинг.
  - Качество: оригинал, MP3 320 / 192, Opus 128.
  - Сыгранные треки остаются на карте (до 1 ГБ; при нехватке места первыми удаляются давно не игравшие).
- **Яндекс Музыка** — плитка появляется только при наличии ключей.
  - Вход по коду с телефона на `ya.ru/device` или по QR.
  - Разделы: «Мне нравится», «Моя волна» (с лайками, дизлайками и пропусками), плейлисты, поиск, альбомы, исполнители.
  - Форматы: FLAC, FLAC в MP4, AAC в MP4, MP3; зашифрованные потоки (AES-128-CTR) расшифровываются.
  - Встроен в общий интерфейс сервисов: звезда на экране воспроизведения ставит лайк, есть свой значок и «Показать альбом»; Wi-Fi не паркуется во время загрузки; кеш до 1 ГБ, чистится при выключении.
- **Общий интерфейс для стриминговых сервисов (provider table).** Qobuz, Tidal, Subsonic и Яндекс подключаются через одну таблицу вместо проверок по всему коду. Поведение Qobuz и Tidal не изменилось.
- **Фрагментированный MP4 (DASH, CMAF, `frag_keyframe`)** играет и перематывается, в том числе пока докачивается. Это закрывает Tidal в AAC-качестве.

**Bluetooth**
- **Заряд любых наушников** по HFP (`-p hfp-ag`). Опция, по умолчанию выключена. Показывается в настройках Bluetooth-аудио и в строке наушников.
- **Режим LDAC (990 / 660 / 330 / ABR) запоминается для каждых наушников.**

**Интерфейс**
- Редко открываемые экраны строятся при первом открытии: радио, эквалайзер, PEQ, MSEB, AutoEq, «Процессы». Это −1120 объектов после загрузки.
- Подпись для вкладки «Треки» в поиске стриминговых сервисов. Ключ `tracks_2` отсутствовал и в оригинале.

### 1.2.1 — 12.10.2026: первая и вторая волны

**Библиотека**
- **Сборники** с флагом COMPILATION и без ALBUMARTIST собираются в один альбом «Various Artists». Нужен полный рескан.
- **Альбомы исполнителя и жанра идут по году выпуска.** Новая настройка, включена по умолчанию. «Играть исполнителя» следует тому же порядку.
- **«Перейти к исполнителю»** в меню трека, в меню экрана воспроизведения и по тапу на имя исполнителя. Для сборников открывается сам исполнитель трека.
- **Сортировка альбомов «По исполнителю»:** исполнитель альбома → год → название.
- **Плитки «Недавно добавленные» и «Недавно играли»** на странице «Музыка», до 100 элементов.
- **Длительности треков** (м:сс) в списках, «N треков · M мин» в шапке альбома.
  - Длительность берётся из заголовков файлов без декодирования: FLAC, MP4/M4A/M4B, WAV, DSF, APE, MP3 (Xing/VBRI/CBR), Ogg/Opus, WavPack.
  - Нужен полный рескан.
- **FLAC читается за одно открытие файла при скане** — примерно в 3 раза меньше чтения с карты.
- **Поиск:**
  - все слова запроса в любом порядке, по названию, исполнителю, альбому и исполнителю альбома;
  - ё/е и регистр не различаются;
  - один проход без отдельного COUNT;
  - ключи поиска для старой базы дозаполняются в фоне.
- **ReplayGain:**
  - предусиление −6…+6 дБ;
  - уровень для файлов без тегов (0…−12 дБ);
  - чтение `R128_TRACK_GAIN` и `R128_ALBUM_GAIN` у Opus.

**Bluetooth**
- **AAC с переменным битрейтом (VBR) по умолчанию**, с выбором CBR 220.
- **Частота соединения 44,1 кГц как опция** (`--a2dp-force-audio-cd`): CD-материал идёт без пересчёта.
- **Запоминаются для каждых наушников:** выбранный кодек и громкость.
- **Детали кодека:** «LDAC 990 · 48 kHz» и т.п. в настройках и в строке наушников. Добавлен LDAC 330.
- **Переподключение после паузы:**
  - проверка, что контроллер отвечает;
  - ожидание самостоятельного переподключения 3 с вместо 8, если связь была недавно;
  - настройка «Держать Bluetooth включённым» (15 с / 1 / 5 / 15 мин).
- **Эквалайзер для каждого выхода** (3,5 мм, 4,4 мм, USB, Bluetooth, конкретные наушники). Опция, по умолчанию выключена.
- **LDAC 990 уступает Wi-Fi-трансферу:** пока он включён, используется 660; переключение — только когда музыка не играет.
- Модуль ресемплера 44,1 → 48 кГц написан и проверен тестом, но **не подключён** к воспроизведению.

**Сеть**
- **Загрузки Qobuz, Tidal и подкастов докачиваются после обрыва соединения** (HTTP Range, до 4 попыток). Сегменты Tidal DASH повторяются.
- **AES-128 (CTR и CBC) через OpenSSL прошивки**, с самопроверкой по векторам NIST.

**Скорость и батарея**
- **Главный экран рисуется до построения остальных экранов:** первый кадр примерно в 1,7 раза быстрее на хосте.
- **OpenSSL загружается в фоне после первого кадра;** имена языков читаются один раз, а не все `.ini` целиком.
- **Позиция трека пишется на карту раз в 30 с вместо 10** и обязательно перед сном.
- **Бегущая строка перерисовывается ~28 раз в секунду вместо 60.**
- **Размытие под строкой состояния не пересчитывается**, пока шторка плеера движется.
- **Кеш глифов FreeType 256 → 1024**, декодеры обложек собраны с `-O3`.
- **Подсказка последовательного чтения** для воспроизводимого FLAC/MP3.
- Два режима добавлены, но **по умолчанию выключены** до проверки на плеере:
  - тачскрин по событиям (`[display] touch_events = 1`);
  - отрисовка в кешируемую память (`[display] cached_render = 1`).

**Система**
- Версия 1.2.1. Обновления «через интернет» берутся из форка (`ota-repo = Rekkod-Tree/sonix-player-rekkod-mod`).

## 4. Новые настройки

**В интерфейсе**
- **Настройки Bluetooth-аудио:**
  - Частота: Авто (48 кГц) / 44,1 кГц / По треку / 96 кГц;
  - AAC: VBR / CBR 220;
  - Держать Bluetooth включённым: 15 с / 1 / 5 / 15 мин;
  - Заряд наушников (HFP);
  - строка «Авто» в списке кодеков;
  - LDAC 330.
- **Эквалайзер:** «Эквалайзер для каждого выхода».
- **Библиотека:**
  - «Альбомы исполнителя по году»;
  - сортировка альбомов «По исполнителю»;
  - заметка о рескане для длительностей.
- **Воспроизведение:** предусиление ReplayGain, уровень для файлов без тегов.
- **Стриминг → Subsonic:** вход, качество, очистка загруженного, выход.
- **Стриминг → Яндекс Музыка:** вход по коду или QR, выход.

**Ключи `device_config.ini`**

| Секция | Ключ | Значения / смысл |

| | `bt_aac_mode` | `vbr` / `cbr` |
| | `bt_codec_<MAC>` | кодек, закреплённый за наушниками |
| | `bt_ldac_<MAC>` | режим LDAC для наушников |
| | `bt_volume_<MAC>` | громкость для наушников |

| | `resampler` | `fast` / `quality` (пока ни на что не влияет) |

| `[eq]` | `per_output`, `po_*`, `pn_*`, `po_live` | эквалайзер для каждого выхода |

Сессии сервисов хранятся рядом с конфигом: `yandex_session.ini` для Яндекса, токен и соль в `[subsonic]` для Subsonic.

## 5. Ограничения и непроверенное

- **На плеере не проверено ничего.** Чеклист — в `sonix-r1/04-release-1.2.3.md` проекта.
- **Tidal, Qobuz, Podcast Index, Last.fm не работают.** Ключ к запечатанному файлу ключей автор вкомпилирует только в свои сборки. Свои ключи Podcast Index и Last.fm можно получить бесплатно и запечатать ключом форка; для Tidal и Qobuz легального способа нет.
- **Яндекс Музыка** проверена только на имитации сервера. Ключи и подписи взяты из открытых клиентов и могут смениться.
- **«По треку» и «96 кГц»** зависят от того, примут ли наушники смену частоты без перезапуска.
- **Ресемплер 44,1 → 48** не подключён.
- **FLAC в MP4 у Яндекса** не показывает общую длину.
- **Обновление «через интернет»** с форка не работает, пока нет GitHub Release.
